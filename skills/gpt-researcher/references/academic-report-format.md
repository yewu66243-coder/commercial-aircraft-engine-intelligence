# 规范论文格式报告参考

本参考用于约束商用航空发动机情报收集系统的最终报告写作与导出。目标是生成接近学术论文/技术情报研究报告的中文文档，而不是松散的汇报提纲或资料摘录清单。

## 必备文档结构

最终面向用户的正式报告必须按以下顺序组织：

1. 封面：包含报告题名、报告类型、生成机构和成文日期。
2. 摘要页：标题为`摘要`，证据允许时写300-500字中文摘要，覆盖研究目的、资料与方法、主要发现和结论边界。
3. 关键词：使用`关键词：`开头，列3-5个关键词，关键词之间用中文分号分隔。
4. 目录：标题为`目录`；DOCX导出必须基于真实Word标题样式生成自动目录字段，不使用手工页码目录。
5. `1 引言`：说明背景、研究对象、问题范围和研究意义。
6. 专题分析章：使用连续一级编号，例如`2 技术风险与受影响部件`、`3 适航响应与服务文件进展`、`4 维修执行与运营影响`。具体章名由任务框架和证据决定，不固定套用同一目录。
7. 二级标题：仅在有助于组织论证时使用，编号为`2.1`、`2.2`等。
8. `综合讨论与研究局限`或`综合研判与后续监测重点`：比较不同来源的一致性、分歧、数据缺口和推断边界。
9. `结论与建议`：回应研究问题，不引入新事实。
10. `参考文献`：按正文首次出现顺序编号，与正文引用一一对应。

`资料来源与研究方法`不是默认公开章节。除非用户明确要求或任务本身是方法论报告，否则检索范围、源站权重、资料覆盖和待核验事项进入后台记录、内部核验节，或在引言/综合讨论中用一两句话说明。

## 论证结构要求

正式报告必须先回答“用户为什么要看这份报告”。章节顺序应体现问题链条，例如“对象和事件背景—技术或制度原因—影响传导—对比研判—建议”。不要按资料到达顺序、来源类别或子任务编号机械拼接。

每个公开专题章节应具备三个要素：

- 章节问题：这一章解决什么具体问题。
- 证据组织：哪些来源、数据、案例或文件支撑这一章。
- 分析功能：这一章如何推动全文结论，而不是重复摘录材料。

写完后应进行反向提纲检查：只看各章节首句和段落主题句，仍能看出全文论证路线。如果看不出，应重排章节、合并重复段落或补足承接句。

## 行文要求

正文使用连续学术段落，段落自然包含观点、证据、分析和衔接。不要输出`分论点`、`证据事实`、`推理过程`、`对任务的影响`等汇报标签，也不要在正式正文中保留可见的内部核验标记。

保留证据中的型号、部件名称、日期、数量、单位、适用范围和来源限制。缺少证据只能表述为资料缺口，不能推断为对象不存在问题。事实、推断和建议必须区分清楚。

不要把没有把握的判断先写成确定事实，再追加`所查资料未提供`、`证据来源不清楚`、`尚无法证实`、`需核验`等兜底句。处理方式按优先级为：删除该断言；收窄成材料能够支撑的判断；转入内部核验记录；在综合讨论中集中说明后续监测重点。

模型只负责生成语义化Markdown和证据编号。页面排版由导出器负责，不要求模型模拟分页、封面空行、目录页码或Word样式。

## 引用与参考文献规范

草稿正文使用内部证据编号，例如`[原文1]`和`[URL1]`。系统必须将其转换为公开引用，例如`[[1]](#ref-1)`，并按首次出现顺序生成`参考文献`。

参考文献采用GB/T 7714-2025风格的顺序编码制、标点和类型标识：

- 本地报告或内部资料：`[序号] 作者. 题名[R]. 本地资料.`
- 期刊论文：`[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.`
- 在线期刊论文：`[序号] 作者. 题名[J/OL]. 刊名, 页码或出版状态[访问日期]. URL.`
- 学位论文：`[序号] 作者. 题名[D]. 授予单位, 年.`
- 专利：`[序号] 专利权人. 专利题名: 专利号[P]. 公告日.`
- 网络资料：`[序号] 作者或机构. 题名[EB/OL]. 发布日期或访问日期. URL.`

在线期刊论文示例：`[1]张骁雄,丁松,范强,等.多分支特征增强的航空发动机剩余寿命预测方法[J/OL].计算机集成制造系统,1-27[2026-09-09].[https://doi.org/10.13196/j.cims.2026.0129](https://doi.org/10.13196/j.cims.2026.0129).`

作者、日期、刊名、页码、专利号等未知时应省略未知字段，不得编造。参考文献中不得出现`查看原始资料`等界面式措辞。长URL只放在参考文献中，不放入正文段落或表格单元格。

## DOCX导出规范

DOCX使用A4纸张、清晰页边距、黑色中文学术排版和真实Word标题样式。封面保持干净，不显示页眉页脚；正文页可使用简短报告题名页眉和居中页码页脚。

目录基于Word标题样式生成，默认包含1-2级标题。目录在Word中应可更新，不应产生只溢出一行的近空白页。

表格使用浅灰色网格边框、浅蓝色表头、可读内边距、垂直居中和必要的重复表头。图片居中放置，图题和图源紧邻图片。

参考文献使用悬挂缩进和正常可读字号。本地来源可以保留可点击链接，但可见文字应是`本地资料`这类学术表达，不使用界面按钮式文案。

## 回归检查

涉及报告格式的代码变更至少覆盖以下检查：

- 正式报告Markdown固定包含目录结构。
- DOCX输出包含封面，并隐藏首页页眉页脚。
- DOCX输出包含真实TOC字段。
- 表格有浅灰色内部边框和浅蓝色表头。
- 参考文献包含`[R]`、`[EB/OL]`等文献类型标识。
- 三智能体流水线仍能输出Markdown、PDF和Word。

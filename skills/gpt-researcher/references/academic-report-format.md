# 规范论文格式报告参考

本参考用于约束商用航空发动机情报收集系统的最终报告写作与导出。目标是生成接近学术论文/技术情报研究报告的中文文档，而不是松散的汇报提纲。

## 必备文档结构

最终面向用户的正式报告必须按以下顺序组织：

1. 封面：包含报告题名、报告类型、生成机构和成文日期。
2. 摘要页：标题为`摘要`，证据允许时写300-500字中文摘要，覆盖研究目的、资料与方法、主要发现和结论边界。
3. 关键词：使用`关键词：`开头，列3-5个关键词，关键词之间用中文分号分隔。
4. 目录：标题为`目录`；DOCX导出必须基于真实Word标题样式生成自动目录字段，不使用手工页码目录。
5. `1 引言`：说明背景、研究对象、问题范围和研究意义。
6. `2 资料来源与研究方法`：说明真实资料范围、归纳比较方法和资料限制，不编造系统综述流程、检索式或验证通过率。
7. 专题分析章：使用连续一级编号，例如`3 技术机理`、`4 适航响应`、`5 维修保障与市场影响`。
8. 二级标题：仅在有助于组织论证时使用，编号为`3.1`、`3.2`等。
9. `综合讨论与研究局限`：比较不同来源的一致性、分歧、数据缺口和推断边界。
10. `结论与建议`：回应研究问题，不引入新事实。
11. `参考文献`：按正文首次出现顺序编号，与正文引用一一对应。

## 行文要求

正文使用连续学术段落，段落自然包含观点、证据、分析和衔接。不要输出`分论点`、`证据事实`、`推理过程`、`对任务的影响`等汇报标签，也不要在正式正文中保留可见的内部核验标记。

保留证据中的型号、部件名称、日期、数量、单位、适用范围和来源限制。缺少证据只能表述为资料缺口，不能推断为对象不存在问题。事实、推断和建议必须区分清楚。

模型只负责生成语义化Markdown和证据编号。页面排版由导出器负责，不要求模型模拟分页、封面空行、目录页码或Word样式。

## 引用与参考文献规范

草稿正文使用内部证据编号，例如`[原文1]`和`[URL1]`。系统必须将其转换为公开引用，例如`[[1]](#ref-1)`，并按首次出现顺序生成`参考文献`。

参考文献采用接近GB/T 7714的标点和类型标识：

- 本地报告或内部资料：`[序号] 作者. 题名[R]. 本地资料.`
- 期刊论文：`[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.`
- 学位论文：`[序号] 作者. 题名[D]. 授予单位, 年.`
- 专利：`[序号] 专利权人. 专利题名: 专利号[P]. 公告日.`
- 网络资料：`[序号] 作者或机构. 题名[EB/OL]. 发布日期或访问日期. URL.`

作者、日期、刊名、页码、专利号等未知时应省略未知字段，不得编造。参考文献中不得出现`查看原始资料`等界面式措辞。长URL只放在参考文献中，不放入正文段落或表格单元格。

## DOCX导出规范

DOCX使用A4纸张、清晰页边距、黑色中文学术排版和真实Word标题样式。封面保持干净，不显示页眉页脚；正文页可使用简短报告题名页眉和居中页码页脚。

目录基于Word标题样式生成，默认包含1-2级标题。目录在Word中应可更新，不应产生只溢出一行的近空白页。

表格使用浅灰色网格边框、浅蓝色表头、可读内边距、垂直居中和必要的重复表头。图片居中放置，图题和图源紧邻图片。

参考文献使用悬挂缩进和正常可读字号。本地来源可以保留可点击链接，但可见文字应是`本地资料`这类学术表达，不使用界面按钮式文案。

## 回归检查

涉及报告格式的代码变更至少覆盖以下检查：

- 正式报告Markdown固定包含目录结构。
- DOCX输出包含封面，并隐藏首页页眉页脚。
- DOCX输出包含真实TOC字段。
- 表格有浅灰色内部边框和浅蓝色表头。
- 参考文献包含`[R]`、`[EB/OL]`等文献类型标识。
- 三智能体流水线仍能输出Markdown、PDF和Word。

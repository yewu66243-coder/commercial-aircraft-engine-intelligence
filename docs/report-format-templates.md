# Word 报告模板

在前端“报告格式设置”中导入 `.docx` 文件。系统单独保存模板，不将模板正文加入资料库或研究证据。模板上限为 10 MiB，第一阶段支持单节、常规单栏文档；多分节模板会提示先合并分节。

## 使用流程

1. 下载“标准模板”，或准备一份排版合格的历史报告。
2. 导入后查看识别结果、缺失项目和格式控件。
3. 默认仅采用排版，章节仍由当前任务规划。需要固定结构时勾选“采用模板章节”，并在文本框中编辑。
4. 点击“下载排版示例”获取示例 Word，检查实际版式，再生成正式报告。此操作不启动情报检索。
5. 已导入的模板出现在下拉列表中，可再次选择。选择“系统默认格式”可以恢复默认排版。

手动修改的控件优先于模板。未修改项继续保留模板值，包括固定行距、不对称页边距和各级标题的不同格式。

## 模板制作

建议在 Word 中为正文、标题、一级至三级标题设置相应段落样式，并留下简短正文、图表题注和参考文献示例。正文识别综合段落样式与示例中的直接格式；未发现的项目会显示提示。

标准模板支持以下占位符，Word 将其拆分到多个文本片段时也能替换：

- `{{REPORT_TITLE}}`：报告标题，可用于封面和页眉。
- `{{REPORT_DATE}}`：成文日期。
- `{{REPORT_BODY}}`：正文插入起点，放在封面后的独立段落中。

模板原有的示例正文会被替换。未使用正文占位符的历史报告，系统优先以“摘要”“目录”或首个一级标题定位正文；前方有标题样式时视为封面。建议先试排核对。封面中的其他固定机构文字以及页眉页脚 Logo 会保留。

正文中的章节编号由报告结构生成，模板的自动章节编号不重复叠加。第一阶段不保证浮动文本框、复杂多栏、自定义多级编号及复杂封面完全复刻。

## 输出与运行环境

Word 从原模板生成，保留页眉页脚、图片关系与页面设置。模板报告的 PDF 由该 Word 文件转换，优先使用 Windows Microsoft Word 自动化服务，其次使用 LibreOffice。需要在运行系统的账户下完成 Word 首次启动，并保证该账户可以使用自动化服务。

LibreOffice 可通过 `.env` 的 `REPORT_LIBREOFFICE_PATH` 指定 `soffice.exe` 完整路径。转换不可用时，报告生成记录会提示 PDF 导出失败，已生成的 Word 和 Markdown 仍可下载。未使用模板时沿用现有 PDF 导出方式。

网页预览和 Markdown 展示内容结构，不承诺复现 Word 的分页与页眉页脚。模板中的字体需要在生成报告的电脑上安装。

模板及识别记录保存于 `local_docs/report_templates/`。交付另一台电脑时需要一并复制该目录。

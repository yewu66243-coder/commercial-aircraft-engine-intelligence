# 测评样本与原文核验

## 2026-09-23 优化

针对 bc8f 任务的测评记录，原程序依赖内部实体清单，正文没有该表时返回0个实体。该任务又只使用本地论文引用，没有公开URL样本，同时未提供标准答案，因此多项显示“无法计算”。原始运行记录实际已保存本地原文，问题并非全部资料缺失。

本次调整如下：

- 优先读取原有实体表；缺表时从正文规则提取型号、部分机构及材料词项、数值和单位候选，不要求模型在公开报告中增加内部核验表。
- 排除摘要、来源列表、内部核验附录和图片来源等区域；同一候选与相同语句去重，不跨句借用引用。
- 将本轮 source_catalog 传入测评，直接复用保存的原文片段及页码；来源不唯一、没有正文或没有引用时保留未核验项。
- 对单个原文片段检查词项及全部数值单位；名称命中但数值未齐全时，不判为完全命中。此规则仍不能判断否定关系、计划与实际等复杂语义。
- 初筛主分数使用全部候选为分母，避免过滤未核验项而虚高。测评报告同时展示样本量、核验覆盖率、逐项样例和本地引用可追溯率。
- 无标准答案显示具体原因；无公开URL标明该项未测。公开URL样本为零时，requirement_met为null而不是false；仍不能据此通过98%验收。

实体和参数提取是有限规则的候选抽样，不是完整NER，不评估漏抽率。自动词项初筛与本地原文可追溯率均不能替代独立裁判的正式准确率。独立裁判API本次未接入。

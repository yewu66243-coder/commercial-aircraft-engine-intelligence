# 全库正文向量索引

覆盖论文池、专利池、用户资料库及其子目录。使用 `.env` 中配置的嵌入模型，
当前为本机 Ollama 的 bge-m3。生成报告的大模型选择不影响该嵌入模型。

## 建立与续建

在项目根目录运行：

```powershell
.\build_full_library_index.bat --build
```

程序逐份处理原始文件，每完成一份就提交数据库。再次执行相同命令时，
未发生变化的已完成资料会直接复用。暂停或异常退出时，正在处理的那一份
不会作为完整资料进入检索，下次会重新处理；其他已完成资料保留。

需要隐藏窗口在后台运行时，使用 `.\build_full_library_index.bat --background`。
后台标准输出和错误日志保存在索引目录的 `library-build.stdout.log`、
`library-build.stderr.log`，后续可使用下面的命令检查进度。

```powershell
.\build_full_library_index.bat --status
.\build_full_library_index.bat --stop
```

`--status` 查看进度；`--stop` 请求在当前嵌入批次返回后暂停。
不要同时启动多份建立任务，程序也会通过文件锁阻止重复运行。
后台建立期间需要保持电脑和 Ollama 服务运行。

## 进度与结果

- `local_docs/rag_index/library-build-status.json`：进度、当前文件、当前片段批次。
- `local_docs/rag_index/library.sqlite3`：正文片段、来源定位、向量及每份文件状态。
- `processed` 为本次处理数量，`indexed` 为本次成功建立数量，`reused` 为复用数量。
- `document_status_counts` 为本轮结束时数据库中各状态的文件数量。
- `completed_with_errors` 表示扫描结束但存在失败或不支持的文件，不代表全库均已成功。
- `no_text` 可能是扫描件、空文档或解析失败，须逐份检查后转换或进行 OCR。
- `unsupported` 表示格式不支持，例如旧版 `.doc`、`.xls`，不能计入正文索引完成量。

完整扫描结束后，已不在资料库中的文件会从索引移除。模型切换或正文改变后，
再次执行建立命令会更新相应索引。未更新的变更文件不会参与全库正文检索。

## 接入报告

重启系统后，报告任务会按前端勾选的检索范围搜索已提交的全库正文片段，
把正文相关但摘要初筛没有选中的资料补充到精读列表。已有索引的资料复用向量，
未建立索引的入选资料仍可走按需建立流程。任务运行记录含 `library_rag` 检索统计。

PDF 引用保留页码；Word、表格、文本采用文件及片段定位，不编造页码。
索引目录已排除在 Git 之外。

## 上传资料后的自动索引

前端“资料上传”会先保存文件并更新摘要索引，因此文件会立即出现在对应资料库中。
随后系统会把该文件加入 `local_docs/rag_index/upload_jobs.sqlite3` 后台队列，
由独立 worker 建立全文向量索引。页面中的索引任务列表会显示排队、等待全库锁、
OCR、分块嵌入、完成或失败状态，并支持失败后重试。

如果正在运行 `--build` 或 `--repair` 全库补建，新上传文件不会抢占同一个
`library.sqlite3` 写入锁，而是显示为等待；全库任务释放锁后会自动继续。
扫描件 PDF 会按需调用本地 RapidOCR，旧版 DOC 会复用本地 Word/缓存提取正文。
OCR 成功后摘要索引也会刷新为可读正文摘要，失败时文件仍保留在资料库中，
但会在页面标明全文索引未完成。

## 补建扫描件及旧版 Word

```powershell
.\build_full_library_index.bat --background --repair
.\build_full_library_index.bat --pending
```

第一条命令只重试未成功的文件及过期 OCR 缓存对应文件。使用本地 RapidOCR
识别中英文扫描 PDF，低于 0.6 的识别结果不作为检索文本。正文文字按页缓存在
`local_docs/rag_index/recovered_text`，缓存以原文件内容哈希标识，原文件保持不变。
识别过程中可暂停，恢复时从已完成的页继续；整份文档的向量计算完成后再提交。

旧版 DOC 通过本机安装的 Word 以只读、禁用宏的方式提取文字，需要可用的
Windows 登录会话。不会把文档上传到云端 OCR 服务。

第二条命令导出 `local_docs/rag_index/pending-documents.csv`，列出仍未完成的文件。
进度中的 `ocr_page`、`ocr_total_pages` 表示当前识别页数；缓存中的 `empty_pages`
标出未识别到文字的页面，可能为空白、图纸或识别困难页面，需检查原图。

OCR 可以补充检索，但不保证公式、复杂表格、标准编号或每个字符完全正确。
正文片段、精读和来源核验共用带来源标记的缓存；数字和关键技术判断仍应回查原页。

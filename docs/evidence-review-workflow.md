# 原文暂存与独立裁判

每个任务在 `outputs/records/evidence/<运行编号>/` 保留独立证据目录。
暂存区用于运行中交接和事后复核，不自动删除，也不会作为下一轮的事实来源。

- `retrieval_<子任务编号>.json`：写子报告前保存本轮检索上下文、来源、网络原文和搜索诊断。
- `source_catalog.json`：来源定位、页码、原文和具有稳定编号的片段池。
- `final_report.json`：实际发布正文及恢复内部引用编号后的评分文本。
- `judge_samples.json`：首次送交独立裁判的完整判断、实体、引用和原文片段。
- `judge_review_samples.json`：首轮记录，以及未确认项扩大原文后的复核材料。
- `judge_results.json`：逐项结果和两轮原文摘录记录。

评分从排版后的公开正文抽取候选，不使用隐藏实体表覆盖正文。引用编号转换只用于定位原文，不改写判断。
裁判先读取已暂存片段；证据不足或摘录不匹配时，在同一引用的已保存原文中扩大选段并复核一次。
片段相关性同时考虑实体名称、完整句子和数值。检索相关性不是正确性结论，最终仍需独立模型判断。
两轮模型调用共享 `JUDGE_TOTAL_TIMEOUT_SECONDS`。正文中的实体没有引用时，先在本轮保存的原文库中检索相关片段，再提交模型核验；不因缺少句内引用直接判为无法核实。超限、未取得原文和未能确认的项保留在分母中，不能计为通过。
当前候选抽取仍是规则抽取，不是覆盖全部专业实体的人工金标准，也不测量漏抽率。

## 网络检索

Tavily鉴权、额度、限流、请求异常和零结果分别记录。432表示本次实际接口反馈的套餐用量上限。
已知鉴权或额度故障会短暂跳过重复请求；不同密钥独立记录。日志不保存密钥或原始异常响应。
默认启用DDGS备用搜索，先使用简化查询和优先站点，无结果时扩大公开检索。
`WEB_SEARCH_FALLBACK_ENABLED=false` 可关闭备用搜索。它不改变或修复Tavily账户额度。
搜索返回链接后仍须抓取正文，检索摘要不会直接当作已核验的网页全文。
完整诊断随任务记录保存，测评报告列出服务、状态、HTTP状态和说明。

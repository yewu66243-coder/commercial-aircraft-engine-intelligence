# 网页来源筛选与处理记录

本次调整将“检索返回”“取得文本”“初筛通过”“送入综合写作”“正文引用”分别记录。上述环节都不等同于事实核验通过。

## 查询与抓取

- `gpt_researcher/retrievers/web_evidence_policy.py` 中的 `build_topic_queries` 为已识别发动机主题生成四条短查询，包含中文、英文、型号扩展及优先站点查询。未识别主题沿用原有模型规划。
- `three_agent_service.py` 的 `_research_one` 启用该查询计划。界面选择的是“优先网址”：定向查询采用其中一个相关站点，其余查询开放搜索，不再把全部站点拼到每条查询上。
- 每条查询返回数量仍由 `max_search_results` / `cfg.max_search_results_per_query` 控制，本次未提高该参数。
- 搜索结果摘要仅保存为 `snippet`，不视为网页原文。`web_candidates` 记录查询和抓取状态，`web_evidence` 保存实际取得的文本。重复URL合并状态，保留最长原文和全部已记录查询。

## 原文保存与写作选择

- `backend/reporting/source_grounding.py` 的 `build_source_catalog` 不再截取前20个来源；本轮检索和抓取记录全部进入目录。
- 对没有抓取状态的旧式检索结果，兼容补抓仍有20次预算；预算外URL保留并标为未抓取。已经记录的抓取失败不在此阶段重复补抓。此预算不限制保存多少份已经取得的正文。
- 验证页、文本过短、未命中任务发动机型号或系列的页面，以及站点链接目录页，保留原文和排除原因，不送入写作原文上下文。规则可能遗漏只使用别称的相关网页，因此界面支持查看全部被排除来源。
- 综合写作原文预算仍为50,000字符，按相关性、已知发布日期、专题及站点覆盖排序；每个来源最多选择两个相关原文片段，每片最多2,200字符。来源全文留在目录中。原文页码和实际送入的片段另外保存，成稿校订不会覆盖综合写作的选择记录。
- 搜索服务提供的发布日期参与排序；未知日期保持未知，不从URL或抓取时间推定发布时间。历史技术资料不会仅因年代较早被删除。

## 查看处理结果

新报告生成后，在报告预览上方展开“网页来源处理明细”，可筛选正文已引用、未引用、抓取失败或初筛排除的链接。每项显示处理原因和已记录查询。“来源记录 JSON”按钮下载本轮指标和来源记录，详情位于 `run_statistics.web_source_tracking`。

证据目录另存 `web_source_tracking.json`；指标报告的“网页来源处理情况”汇总各环节数量。对于已经进入写作上下文却未被引用的来源，系统只记录这个可观察结果，不虚构模型未采用它的具体理由。

## 离线回放

运行 `portable_python/python.exe tmp/replay_af0e_web_sources.py` 可使用 af0e 的已有抓取快照复核保存与选择流程，生成 `outputs/af0e_网页来源流程回放.md` 和同名JSON。

此回放不调用搜索接口、不重写报告、不重新判定原报告正确率。旧快照缺失的搜索候选和失败URL无法补算。新的短查询是否增加有效网页，需要下一次实际生成报告验证。

## 正文引用检查与补写

`backend/reporting/body_citations.py` 单独检查正式正文段落。摘要、目录、来源列表、内部核验表和图片图源不计入正文引用；相关事实可在一个段落中合并引用，不要求逐句引用。

综合写作及润色结束后，对含具体数量、时间或发动机事件等事实、但缺来源关联的段落准备原文候选，每批最多8段，最多6批。模型只返回段落ID、原文片段ID和逐字引文；程序核对片段、来源、引文和段落范围后插入引用，保留正文文字。表格另加来源行。只有实际建立关联的新增来源才补入来源列表。

这一步不会将实体表、搜索摘要当作原文，也不会按检索结果数量强行增加参考文献。补写失败、响应截断或证据不足会保留原稿及原因，继续交由成稿审校处理。后续审校不能把正文引用全部挪到内部表格，也不能重绑保留编号的来源。导出时再次检查公开正文，图源引用不再掩盖正文无引用的问题。

来源关联不等于事实核验通过。原文存在性检查通过后，断言是否得到充分支持仍由成稿审校与独立核验判断。最终仍缺来源关联时，报告标为需复核；指标报告另列“正文引用关联检查”，不改变正确率的计算口径。

补写的前后稿和处理记录保存在运行证据目录的 `body_citation_repair.json`，指标JSON保留 `run_statistics.content_enrichment.body_citation_repair`；最终检查位于 `run_statistics.report_quality.body_citation_coverage`。运行 `portable_python/python.exe tmp/replay_df3d_body_citations.py` 可离线复现df3d的24处缺引用、三批补写请求和最终导出告警。回放不伪造模型判断，不改写旧报告。
